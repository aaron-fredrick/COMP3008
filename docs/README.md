## Documentation principle

The repository should distinguish three things:

1. **What the assignment requires** — authoritative assignment reference.
2. **What the course teaches** — conceptual lecture/lab guides.
3. **What this project actually implements** — source code and tests.

Where a feature is project-specific rather than a direct lab exercise, the mapping documents say so instead of inventing a course reference.
